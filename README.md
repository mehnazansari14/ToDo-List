# My To-Do List

A simple, responsive to-do list that runs in your web browser. It is built as a standalone HTML page, so no installation or build step is needed.

## Getting started

Open `index.html` in a modern web browser. Add a task using the input field and select **Add task** or press Enter.

## Features

- Add tasks, mark them complete, or delete them.
- Filter the list to show all, pending (not completed), or completed tasks, with counts for each status.
- Clear all completed tasks at once.
- Track your progress and remaining tasks.
- Enjoy subtle entrance, task, completion, and deletion animations.
- Automatically save tasks in the browser's local storage.
- Use on desktop or mobile screens.

Your list is stored in the current browser on your device. It is not synced between browsers or devices.
