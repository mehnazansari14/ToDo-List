# My To-Do List

A simple, responsive to-do list that runs in your web browser. The page markup, styles, and behavior live in `index.html`, `styles.css`, and the page's JavaScript, so no installation or build step is needed.

## Getting started

Open `index.html` in a modern web browser. Keep `styles.css` next to it so the page styles load. Add a task using the input field and select **Add task** or press Enter.

## Features

- Use the navigation bar to switch between all tasks, tasks to do, and completed tasks.
- Add tasks, mark them complete, or delete them.
- Filter the list to show all, pending (not completed), or completed tasks, with counts for each status.
- Clear all completed tasks at once.
- Track your progress and remaining tasks.
- Enjoy subtle entrance, task, completion, and deletion animations.
- Automatically save tasks in the browser's local storage.
- Use on desktop or mobile screens.

Your list is stored in the current browser on your device. It is not synced between browsers or devices.
